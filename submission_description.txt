This project demonstrates a data-driven approach to logistics planning using Python. It creates a reproducible sample dataset and applies data cleaning, key performance indicator (KPI) calculations, regression, and clustering to explore delivery operations. The KPIs include on-time delivery rate, average delivery duration, average delay, transport cost per order, inventory stockout rate, and vehicle capacity utilization. A linear regression model estimates delivery duration using distance, order weight, traffic level, number of stops, and vehicle capacity. K-means clustering groups orders into broad operational profiles based on distance, weight, and number of stops. The script exports cleaned data, KPI summaries, model evaluation metrics, predictions, cluster assignments, and traffic-level summaries to CSV files.

The project is intended as a starter implementation for the Week 1 Strategic Planning and Data Exploration in Logistics task. It illustrates how a repeatable analytical workflow can help managers investigate service reliability, cost efficiency, and resource allocation. The code includes basic checks for duplicate records, missing values, invalid negative values, and derived features such as delay minutes and capacity utilization. The accompanying README explains installation, execution, outputs, limitations, and possible next steps.

All records generated by this script are synthetic examples because no real company dataset was provided. Therefore, the printed metrics are demonstrations rather than evidence of actual business performance. A real deployment would require approved company data, documented KPI definitions, time-based model validation, review by logistics stakeholders, and testing of route optimization against real road distances, vehicle capacities, driver-hour limits, and customer delivery windows. The project provides a transparent starting point for further investigation and responsible decision-making in logistics.
